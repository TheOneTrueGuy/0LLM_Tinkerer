Core

Local stack

  • app.py — UI + ModelManager + WeightInverter
  • model_visualizer.py — graphs & Plotly
  • weight_inversion_implementation.py — inverter used locally and on the pod
Remote

RunPod path

  • runpod_manager.py talks GraphQL + HTTP
  • Handler + inverter are base64-embedded in dockerArgs
  • runpod_handler.py Flask API on port 5000
